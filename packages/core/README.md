## Rules

- Each module exposes a small public interface in its `index.ts`. Other modules import only from that file, never from another module's internals or tables. The import-boundary check enforces this.
- Every service takes an authenticated context (user, tenant, roles) and runs the central permission check before doing anything.
- Every database access goes through `withTenant()` from `@akoso/db`.
- Modules talk to each other through service calls or domain events written to the outbox.

**Status:** placeholders only, plus environment validation in `src/config/`.
